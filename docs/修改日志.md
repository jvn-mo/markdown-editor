## v1.0.2 (2026-07-13)

### 新增
- 多标签页支持：可同时打开多个 Markdown 文件，通过标签栏自由切换
- 标签关闭确认：关闭有未保存更改的标签时会弹出确认提示
- 状态栏：底部新增状态栏，显示当前文件名、保存状态、字数统计和操作反馈
- 独立主题设置：编辑区和预览区可分别设置亮色/暗色主题（工具栏下拉框）

### 修复
- 保存反馈：按 Ctrl+S 保存后，状态栏显示"保存成功"提示
- 导出默认文件名：导出 PDF/DOCX 时，默认文件名自动与当前 MD 文件名保持一致
- 编辑/预览按钮逻辑：点击"编辑"按钮编辑区全屏，点击"预览"按钮预览区全屏，再次点击恢复双栏
- 重复文件打开：已打开的文件再次打开时，自动切换到对应标签而非重复创建

### 调整
- 顶部工具栏新增"编辑器主题"和"预览主题"下拉选择框
- 标签栏位于工具栏下方，支持横向滚动
- 底部新增状态栏（蓝色背景），显示实时操作反馈

### 修复（补充）
- 关闭窗口提醒：关闭应用窗口时，如有未保存的更改，弹出系统对话框询问"保存 / 不保存 / 取消"

## v1.0.2-1 (2026-07-13)

### 修复
- 关闭标签保存：关闭单个标签时，如有未保存的更改（尤其是新建文件），弹出系统对话框询问"保存 / 不保存 / 取消"，点击保存可唤起文件选择对话框

### 调整
- 底部状态栏：蓝色背景改为深色 `#252526`，与整体界面风格统一，更精简低调
- 主题选择器：工具栏上的"编辑器主题"和"预览主题"下拉框已移除，改放到顶部菜单"格式"中作为独立子菜单

### 修复
- DOCX 导出字体：使用 `adm-zip` 后处理 pandoc 生成的 docx 文件，将 `word/styles.xml` 中的默认字体（ascii/hAnsi/eastAsia）统一替换为宋体（SimSun）
