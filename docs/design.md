# Markdown 渲染与导出工具设计文档

## 项目概述

从 AI 对话复制下来的 Markdown 文本直接粘贴到 Word 等软件时，公式、符号、表格会出现乱码。本工具在本地实现一个类似 Typora 的 Markdown 渲染器，支持实时预览并导出为 DOCX 和 PDF 格式。

## 核心需求

| 维度 | 需求 |
|------|------|
| 界面 | 左右分栏（左侧 Markdown 编辑，右侧实时渲染预览） |
| 内容支持 | 标题、列表、表格、代码块、LaTeX 公式（行内+块级）、Mermaid 图表 |
| 导出格式 | DOCX（可编辑）+ PDF（可打印存档） |
| 运行方式 | 本地桌面应用 |
| 附加功能 | 左右栏可手动折叠/展开，隐藏后另一栏占据全屏 |

## 技术选型：Electron + Vanilla JS

选择 Electron 的原因：
- 行业标准（Typora、VS Code、Obsidian 同款技术栈）
- 前端 Markdown 渲染生态最成熟（marked.js + KaTeX + Mermaid + highlight.js）
- 左右分栏实时预览是 Web 技术的天然优势
- 导出 PDF 可直接调用 Electron 内置 API，效果与预览 1:1
- 导出 DOCX 可通过集成 pandoc 实现，工业级转换质量

## 应用架构

```
┌─────────────────────────────────────────────────────────┐
│  Electron 主进程 (Node.js)                              │
│  ├── 窗口管理                                            │
│  ├── 菜单栏（文件 → 打开/保存/导出 PDF/导出 DOCX）        │
│  └── 导出服务：调用 pandoc 转换 DOCX                     │
├─────────────────────────────────────────────────────────┤
│  渲染进程 (Chromium)                                     │
│  ┌──────────────┐  ┌─────────────────────────────────┐  │
│  │  左侧编辑区   │  │        右侧预览区               │  │
│  │  <textarea>  │  │  marked.js → HTML              │  │
│  │  可折叠      │  │  KaTeX → 数学公式               │  │
│  │  语法高亮    │  │  Mermaid → 图表                │  │
│  └──────────────┘  │  highlight.js → 代码块          │  │
│                     └─────────────────────────────────┘  │
│  工具栏：[编辑] [预览] [折叠/展开按钮]                        │
└─────────────────────────────────────────────────────────┘
```

## 功能清单

1. **编辑区**：支持粘贴 Markdown，实时同步到预览区
2. **预览区**：正确渲染所有 Markdown 元素（标题、列表、表格、代码块、公式、Mermaid 图表）
3. **栏位控制**：点击按钮可折叠/展开左侧编辑栏或右侧预览栏，隐藏后剩余栏位占据全屏
4. **导出 PDF**：与预览效果 1:1，支持页眉页脚、分页
5. **导出 DOCX**：通过 pandoc 转换，保留格式、表格、公式
6. **文件操作**：打开 `.md` 文件、保存编辑内容

## 外部依赖

| 依赖 | 用途 | 安装方式 |
|------|------|---------|
| Node.js | 运行 Electron | 项目内自动管理 |
| pandoc | DOCX 导出 | 需手动安装（提供安装指引）|

## 界面布局说明

- 默认状态：左右等宽分栏，中间可拖拽调整宽度
- 编辑栏可折叠：隐藏后预览区占据全屏
- 预览栏可折叠：隐藏后编辑区占据全屏（适合纯写作场景）
- 两个栏都可通过顶部工具栏按钮控制
